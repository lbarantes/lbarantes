### 👨‍💻 Sobre mim

Sou **Engenheiro Full Stack** e gosto de cuidar do produto de ponta a ponta: modelagem de banco, APIs, frontend, infraestrutura e deploy. Atualmente atuo como **Supervisor e Desenvolvedor**, coordenando uma equipe de BI e automação enquanto desenvolvo os sistemas internos da empresa.

Fora do trabalho, lanço meus próprios produtos: SaaS multi-tenant com WhatsApp e cobrança recorrente, um cliente de banco de dados nativo escrito em Rust e, em paralelo, um navegador e uma linguagem de programação.

- 🎓 Cursando **Sistemas de Informação** na FeMASS.
- 🛠️ Agora: escrevendo o compilador da **BEL**, minha linguagem de programação educacional.
- 🌐 Cada projeto abaixo tem uma página própria em **[beliene.com.br](https://beliene.com.br)**, com o que faz e como foi construído.
